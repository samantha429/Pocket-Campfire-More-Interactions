This is an unoffical fork of Pocket Campfire.
This mods seeks to revamp how you can interact with your mons. 
## Features:
### Interact Menu
- "Show Off" options
- Cuddle
- "Intimacy" options
### Sex
- More sex scenes
- Mon specific scenes
### Mod support
- Allow modders to create their own sex scenes, "Show Off" options, etc.
- Allow modders to create their own mons.
